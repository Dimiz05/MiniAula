## Getting started

You’ll need [Node.js](https://nodejs.org/) and npm. If the project specifies a Node.js version in `.nvmrc` or `package.json`, use that version.

Once the project has a `package.json`, run these commands from the repository root:

```sh
npm install
npm run
```

`npm run` lists the scripts defined by the project. Use the matching command below only if the corresponding script appears in that list.

| Command | Typical purpose |
| --- | --- |
| `npm run dev` | Run the project in development mode |
| `npm start` | Start the application |
| `npm test` | Run the tests |

## Configuration

If the project includes an `.env.example` file, copy it to `.env` and set the values required for your local environment. Do not commit secrets or real credentials.
