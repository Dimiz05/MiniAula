¿Por qué usar Context API en aplicaciones React?

Cuando una aplicación crece, múltiples componentes en diferentes ramas del árbol necesitan acceder a los mismos datos de sesión del usuario o tokens de autenticación. En lugar de pasar props a través de componentes intermedios que no los necesitan, React Context proporciona una forma de pasar datos a través del árbol de componentes sin tener que pasar manualmente las propiedades a cada nivel.

Conceptos clave para este módulo:

  • createContext(): Inicializa el contexto con un valor por defecto.
  • Provider: Componente que envuelve el árbol y provee el valor actual (`value={{ user, token }}`).
  • useContext() Hook: Permite que cualquier componente hijo consuma el contexto de forma limpia.
  • Persistencia: Sincronización del estado de autenticación en almacenamiento local con manejo de errores.
